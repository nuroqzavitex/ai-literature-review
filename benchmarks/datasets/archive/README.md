# Archived biomedical gold

Các file trong thư mục này thuộc bộ câu hỏi biomedical cũ. Chúng được giữ để
audit lịch sử, nhưng **không được dùng** để chấm các `topic_id` mới cùng số
thứ tự trong `../topics.json`.

Trước khi chạy RAGAS/paper relevance cho `pos_01`, `pos_02`, `pos_10` hoặc
`pos_12` mới, phải tạo independent gold mới từ nguồn AI/CS phù hợp và freeze
nó trước lượt workflow đầu tiên.
